〇、可视化触发规则总纲

每种图形都不是随意选择的：先判定指标间的业务关系，再由关系触发图形。管理层扫一眼图形即知"该看什么关系"。

规则① 趋势 → 本月数柱 + 月度同比金线（双轴）

触发条件：流量类核心指标（营业收入/利润总额/净利润）。不使用本年累计趋势——累计曲线永远向上，掩盖动能拐点；左轴柱=各月本月数（水位），右轴金线=月度同比%（增速），金额与增速一屏对读。悬停一次三行：本月数 / 去年同月 / 月度同比（三数自洽：去年同月=本月数÷(1+同比)）。KPI 区另保留累计值+预算完成环给规模感。2026-10-27 两轮优化：①柱色加深为主蓝 #0d6ef0 不透明——与卡片名称栏蓝渐变右端同色，全页柱图一个蓝；②月份轴下方增设迷你图例「■本月数 ─●─月度同比」，符号取色与柱线一致，免悬停即可读图。2026-10-28 银行三 hero 趋势窗口扩宽：由「近12月滚动」改 【上年1月—当年10月】22 根柱（跨年纵览：上年 12 个月基线 + 本年迄今，标签全量年份+补零月份「2025/01…2026/10」倾斜 60° 全部显示，2026-10-28 按需求由 25/1 缩写改全量并倾斜；当年止月=所选月与 10 月取大，当年段按报表当月值校准、上年段保持原值；月度同比金线锚定所选月与累计同比收敛，其后为外推段），一眼对比"去年全年节奏 vs 今年动能"。华润金融总览页 hero 保持近12月口径不变。

规则② 层级构成 → 环形饼图

触发条件：分项相加=母项（收入构成、资产负债、五级分类、条线营收）。饼片 ≤6，长尾并「其他」轧差保证饼合计=中心总量；右侧配明细行（值+同比+占比）。配色（2026-10-22 九轮按参考图改浅亮盘）：#4d94ff 亮蓝 → #6cc0f0 浅蓝 → #35c06b 绿 → #eda14e 橙 → #a0b4f0 蓝紫（原藏蓝深色系太深弃用）；语义片保留专属色（权益橙金、五级分类绿→红质量色阶、轧差项浅灰蓝）。悬停三行按指标口径：期间指标（损益/条线营收）=「本年累计数 / 累计同比 / 占比」；时点指标（资产负债/存款结构/五级分类）=「本月末 / 同比 / 占比」。弹框排版（2026-10-31 按需求优化）：每行仅一条指标信息（值、涨跌、占比各占一行，占比不再与值同行括号内联）、去行首前导空格、行距 bodySpacing 4px 放宽，白底+淡蓝细边+柔和阴影皮肤沿用全局规范——消除文字重叠/拥挤。管理层看饼=看结构比例，看行=看谁在拉动。

规则③ 加减链条 → 支出构成（环形饼）

触发条件：指标间是"支出=费用+税金+减值+所得税"的构成关系。2026-10-30 按需求由「利润扣减结构」更名「总支出构成」并删净利润片：环形饼只讲"钱花在哪"，不再承担收入→利润的推导（推导信息由行1卡与左饼承载，去重）。五类支出（业务及管理费/税金及附加/信用减值损失/其他支出/所得税）五片瓜分全圆（五片合计=总支出，勾稽闭合；「其他支出(净收益)」=台账「营业外收支」显示名，净额口径——有时净支出有时净收益，2026-10-30 按需求明细行/悬停读数按台账原符号显示（净收益时为负），饼片宽/占比按 |值|（环形图不支持负片），中心数=五项带符号合计），片宽=占总支出比重，一眼定位"最大出血点"（橙片=信用减值）；中心=总支出合计（=右侧明细行五项之和，数字+单位不带科目名）；右侧明细行与左卡同格式（色点+名称 / 值 / 累计同比 / 占总支出比）。回答管理层的追问："钱是被什么吃掉的？吃掉了多少？"

规则④ 对比 → 条形；红线 → 阈值卡；量级悬殊 → 卡片

无构成关系的科目对比用条形；有监管要求值的用阈值卡（实际值低于红线→红点告警）；单位/量级不同无法同图共存的（比率类 vs 金额类）用卡片并排，不做伪对比。2026-10-26 六卡行统一版式：效益与定价 / 资产负债核心科目 / 监管红线监测三行与「低成本资金来源」同版式=同阅读动作（2026-10-28 起对齐②区「零售财富与低成本存款」组卡版式；资产负债核心科目同日并为三卡+双侧构成一体模块，卡版式不变；2026-10-28 该模块三总量卡为 stx.plain 变体——名称栏无背景纯文字直排、无「本月末」口径标签（模块卡头已占蓝条与口径注，卡内不再叠蓝顶/重复口径），其余六卡行仍为标准蓝渐变名称栏。2026-10-28 监管红线监测六卡行已按需求整体删除——阈值卡规则保留备用：若未来恢复监管指标监测，仍按"实际值低于监管要求→红点告警"规则与六卡统一版式实现）。2026-10-27 修订：贷款结构两项（对公+零售）经勾稽验证相加=贷款总额，已由条形升格为环形饼（满足规则②入饼条件）——条形区仅保留口径交叠科目（如原房地产/绿色等跨条线标签，若恢复时勿改饼）。
