〇、可视化触发规则总纲

与华润银行/华润资产驾驶舱共用同一套图形语言（2026-11-06 对齐定稿）：先判定指标间业务关系，再由关系触发图形；保险业务特有「保费 ↔ 佣金同源双线」结构，另立双主线复合卡范式。

规则① 趋势 → 本月数柱 + 月度同比金线（双轴）

触发条件：流量类核心指标（营业收入/利润总额/净利润）。2026-11-12 按需求：保费规模/佣金收入两卡趋势图删除（双主线卡收敛为「构成饼+明细行」，总量由饼中心承载）。不使用本年累计趋势——累计曲线恒向上掩盖动能拐点；左轴柱=各月本月数（保险源表「当月值」列直读、末月校准），右轴金线=月度同比%。趋势窗口=【上年1月—当年所选月】22 根柱（2026-11-06 由近12月滚动升级，与银行页同构：BK_SHAPE 月度形状年化拆分、标签「2025/01…」全量倾斜、金线锚定所选月）。柱色=亮蓝 #4d94ff，月份轴下固定迷你图例「■本月数 ─●─月度同比」+「🎯 考核指标」注（ins01 三项全★）。悬停三行：本月数 / 去年同月 / 月度同比。单位=万元（保险报表口径，与资产/银行亿元区分）。

规则② 层级构成 → 环形饼图（勾稽前提）

触发条件：分项相加=母项。保险页全部饼均严格勾稽闭合、零轧差片：保费四大板块（机构+产融+香港+市场化）=保费规模合计、佣金同口径四板块=佣金合计（46,800+48,600+15,200+20,000→见附A 八式全验）。饼片 ≤6，中心=母项总量（2026-11-12 起双主线卡 hero 已删，中心即总量唯一承载），右侧明细行（色点+板块 / 值 万元 / 同比 / 占比）〔2026-11-16 曾按报表层级展开分组明细，同日按需求回退至四板块版〕。配色与银行统一：#4d94ff → #6cc0f0 → #35c06b → #eda14e。管理层看饼=看板块结构，看行=看谁在拉动；两饼同序同色 = 同板块保费片与佣金片角度/宽度可对读 → 板块佣金率（佣/保）免计算直观可得（产融 15.5% > 机构 16.1%？不——机构 425,600 保/68,500 佣=16.1%、产融 312,800/48,600=15.5%、香港 98,500/15,200=15.4%——饼对读直接暴露"集团渠道费率最高"的议价事实）。

规则③ 二层下钻 → 树形行式明细（非图）

触发条件：某饼片需要展开第二层（产融板块 31.7% 是全盘战略重心）。保险 02 表的产融层级达 三级（产融→燃气→华润/市场燃气；创新场景→社区/职域/其他融融），饼图只承载一层（二层入饼即双重计算）。故产融板块用缩进树形行式明细（├│└ 结构字符 + 「其中：」层级）表达父子关系，父行=饼片值互证（燃气+商户+银保+创新=312,800 附A）；★考核叶子（华润燃气 88.30%）行尾直标达成率——树负责"口径路径"，卡负责"考核结果"。

规则④ 量级悬殊/单位不同 → stx 卡片

比率（%）、金额（万元）、户数（万户）不共图，统一银行同款 stx 卡六段式：蓝渐变名称栏（🎯考核/⭐高质量徽章右贴，与银行 bkBadges 同图标语言）→ 口径行「本年累计」→ 蓝渐变大数值 → 同比+环比同行（红涨绿跌带箭头）→ 考核项预算三段式进度条（左「预算」/中主蓝条内白字达成%/右预算值；源表无预算列则整行不渲染，不造数）。保险计量周期=当月动作量，环比是保险销售节奏的固有指标（开门红/月末冲量），故 stx 卡变动小注=「同比+环比」组合（银行对公余额类用同比+较年初，同一卡片体系按业务节奏选小注类型）。

规则⑤ 复合卡范式（保险特有）

保费与佣金是保险经纪/代理业务的双主线（先收保费、按费率转佣金，两者同源同板块），管理层对每条主线的完整追问链=「总量多少 → 动能如何 → 结构在哪」。故本 tab 设「复合卡」：单卡内纵向完成 KPI 三段式（预算环/累计/本月数）→ 22 月趋势（规则①）→ 构成饼+明细行（规则②） 三个阅读动作，免去跨模块视线往返。两卡左右并排（g2）保持双主线对照关系。
