〇、可视化触发规则总纲

每种图形都不是随意选择的：先判定指标间的业务关系，再由关系触发图形；华润资产与华润银行共用同一套图形语言（2026-11-06 对齐），并针对「同一指标多口径并存」的资产报表特点增设规则⑤。管理层扫一眼图形即知"该看什么关系"。

规则① 趋势 → 本月数柱 + 月度同比金线（双轴）

触发条件：流量类核心指标（营业收入/利润总额）。不使用本年累计趋势——累计曲线永远向上，掩盖动能拐点；左轴柱=各月本月数（水位），右轴金线=月度同比%（增速）。趋势窗口与银行页同款 【上年1月—当年所选月】22 根柱（跨年纵览，标签「2025/01…2026/09」全量倾斜显示；当年段按 BK_SHAPE 月度形状由累计年化拆分，月度同比金线锚定所选月与累计同比收敛）。柱色=亮蓝 #4d94ff（与饼图主片、预算进度条同族）；月份轴下方固定迷你图例「■本月数 ─●─月度同比」，符号取色与柱线一致，免悬停即可读图。悬停一次三行：本月数 / 去年同月 / 月度同比。KPI 区另保留累计值+预算完成环给规模感。

规则② 层级构成 → 环形饼图（含整圆前提）

触发条件：分项相加=母项（四大业务线自有出资=存量；单体口径业务线收入=营收）。饼片 ≤6，中心标母项总量，右侧配明细行（色点+名称 / 值 亿元 / 同比 / 占比）。配色与银行页统一：#4d94ff 亮蓝 → #6cc0f0 浅蓝 → #35c06b 绿 → #eda14e 橙。整圆前提的两种轧差处理（2026-11-06）：明细合计 < 母项 → 补「其他/未拆分收入」浅蓝片使饼闭合；明细合计 > 母项（资产单体口径业务线存在跨条线交叉双计）→ 不加负片（环形图不支持负值），改在明细区追加「条线互抵轧差」灰注行，使明细行算术=中心总量——宁显式披露口径缺陷，不做伪闭合。

规则③ 加减链条 → 瀑布（本页暂无触发项）

触发条件：指标间存在严格闭合的"收入−成本−费用−减值=利润"加减链。资产 01 表损益科目（营业成本/业务及管理费用/人工成本/利息支出/拨备两行）之间存在层级交叠（人工成本⊂管理费用、利息支出处置口径不明），演示数据下 收入−成本−费用 ≠ 拨备前利润，不满足入瀑布前提，本页不设瀑布图；损益推导信息由 hero 累计值 + 效益四卡承载。若未来供数补齐互斥成本分项，可按银行页「支出构成」同款环形饼升格。

规则④ 对比 → 条形；量级悬殊/单位不同 → 卡片

无构成关系的科目对比用条形（新增 vs 退出=一进一退分组条形；风险资产分布；全口径对比；协同规模三指标）；单位或量级不同无法同图共存的（亿元 vs 个 vs %）用银行同款 stx 卡片并排，不做伪对比。风险类保留语义色：红=不良、橙金=关注（风险信号色不参与主蓝统一）。stx 卡五段结构与银行页规则⑤完全一致：蓝渐变名称栏（★考核）→ 口径行（本年累计/本月末/本季末三态）→ 蓝色渐变大数值 → 同比+较年初同行小注（红涨绿跌）→ 考核项预算三段式进度条（左「预算」→ 中主蓝进度条内白字达成% → 右预算值）。

规则⑤ 多口径指标 → 口径页签 + 全口径对比并存（资产特有）

资产四张报表的指标带「合并/本部/单体」层级口径（财务考核=横琴+渝康、本部=横琴+香港、横琴/渝康单体、香港口径）。口径间是包含关系而非构成关系——相加≠母项（单体间有内部抵销），因此口径永远不做饼、只做两件事：①分区口径页签切换单口径视图（页签选中色与卡头蓝渐变同色 linear-gradient(90deg,#39a1f7,#0d6ef0)，2026-11-06 对齐银行）；②全口径对比条形图同时展示全部口径并金色高亮当前所选——页签读"这一个口径内部结构"，对比图读"口径间相对分量"，两视图互补。卡片随口径展示该口径实有指标，缺失显示 —（不造数）。
